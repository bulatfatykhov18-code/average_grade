# average_grade
Программа на Python вычисляет средний балл по списку оценок, которые вводит пользователь. Она рассчитана на многократное использование в рамках одного запуска: после расчёта среднего балла пользователь может либо запустить новый расчёт, либо завершить работу программы.

Ключевые возможности:

Ввод оценок: пользователь вводит оценки через пробел (поддерживаются дробные значения, например 4.5 5 3).
Расчёт среднего арифметического: программа считает среднее по всем введённым оценкам и выводит результат с точностью до двух знаков после запятой.
Повторные расчёты: после каждого расчёта можно начать заново без перезапуска программы.
Защита от некорректного ввода:
игнорирует пустой ввод;
отклоняет нечисловые значения (буквы, спецсимволы);
требует корректного выбора действия (только 1 — заново, 2 — выход).
Инструкция для запуска (для GitHub)
Требования
Python версии 3.6 или выше.
Никаких внешних зависимостей не требуется — используется только стандартная библиотека.
Как запустить
Сохраните код в файл, например average_grade.py.
Откройте терминал (командную строку) в папке с файлом.
Запустите программу командой:
bash
python average_grade.py
(на некоторых системах может потребоваться python3 average_grade.py).
Следуйте подсказкам в консоли:
введите оценки через пробел, например: 5 4 3 5;
после вывода среднего балла выберите 1, чтобы посчитать снова, или 2, чтобы выйти.
Пример работы
Ввод:

text
Введите ваши оценки через пробел: 5 4 4.5 3
Вывод:

text
Ваш средний балл: 4.12
Нажмите 1, чтобы начать заново, нажмите 2, чтобы завершить: 1
Начинаем заново...
Введите ваши оценки через пробел: ...
